# Contributing Guidelines

Thank you for contributing to Katharine Ringo's OpenSSF Scorecard Project.

## How to Contribute
1. Fork repository.
2. Create topic branch: `git checkout -b feature/improvement`.
3. Commit changes with clear messages.
4. Ensure tests and static checks pass.
5. Open Pull Request against `main`.

## Code of Conduct
All participants are expected to maintain professional and respectful collaboration.
