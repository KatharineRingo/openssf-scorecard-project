# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a vulnerability, please report it privately:

- **Email**: `karingo2009@eagle.fgcu.edu`
- **GitHub Security Advisory**: Open a private vulnerability report via GitHub Advisories.

Please provide:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Potential impact.

We will respond within 48 hours and work on a prompt resolution before disclosure.
